OpenCat 🐱
Control OpenCode via Slack

A lightweight, secure bridge that connects your local OpenCode agent to Slack. Trigger tasks, review code, and run tests from your phone or laptop while away from your desk.

npm package: @sheiksadi/opencat Slack Socket Mode (Zero Open Ports) Setup Time: < 2 minutes
Why Did We Build This?

The "Desk Tether" Problem

AI agents are capable of long-running workflows, but working with them usually requires being glued to your terminal.

Pain 01

Locked to the Laptop

You kick off a 10-minute refactoring task or comprehensive test run, and you're stuck at your desk waiting for the agent to finish.

Pain 02

Zero Visibility on the Go

Leaving for coffee or lunch means losing progress updates, status checks, and the ability to course-correct the agent midway.

Pain 03

Port Forwarding / VPN Hassles

Exposing a local dev server to webhooks usually requires ngrok tunnels, public IPs, or corporate VPN firewall exceptions.

The Solution

Meet OpenCat

OpenCat bridges your local OpenCode environment to your Slack workspace using outbound WebSockets.

100% Outbound

No Open Ports

Uses Slack Socket Mode (WSS). Your firewall stays closed. No ngrok, no public webhooks, no infrastructure needed.

Zero Collision

Personal Bot Per Peer

Each engineer connects their own bot (e.g. @opencat-sadi). You control your local machine with total isolation.

Smart Context

Thread Continuity

Conversations in the same Slack thread share the same OpenCode session. Send follow-ups seamlessly or type reset to start fresh.

Getting Started

3 Steps to Get Up & Running

Everything is packaged into an npx CLI command. No cloning, no build commands, zero setup friction.

1

Get the 1-Click Manifest & Create Your Bot

Run npx @sheiksadi/opencat manifest and paste the JSON at api.slack.com/apps.

2

Grab Your Two Slack Tokens

Copy your Bot User Token (xoxb-...) and App-Level Token (xapp-...).

3

Configure & Start

Run npx @sheiksadi/opencat setup to paste your tokens, then type Y to start listening!

Step 1 Detail

1-Click Slack App Manifest

Run this command to output the pre-configured Slack configuration:

# Output the complete JSON manifest
npx @sheiksadi/opencat manifest

How to apply in 30 seconds:

1. Go to api.slack.com/apps ➔ Create New App.

2. Choose From an app manifest.

3. Select workspace ➔ choose JSON tab ➔ paste.

4. Name your bot (e.g. OpenCat - John) & click Create.

Pre-configured Permissions:

✅ Socket Mode enabled

✅ Channels & DMs (chat:write, app_mentions:read)

✅ Emoji reactions enabled (reactions:write)

✅ File handling (files:write, files:read)

Step 2 Detail

Copying the Two Tokens

Slack requires two specific tokens for Socket Mode operation:

Token #1

Bot User OAuth Token

Starts with: xoxb-...

1. In Slack app settings sidebar, click OAuth & Permissions.

2. Click Install to Workspace and authorize.

3. Copy the Bot User OAuth Token.

Token #2

App-Level Token

Starts with: xapp-...

1. In sidebar, click Basic Information.

2. Scroll down to App-Level Tokens ➔ Generate Token.

3. Name: opencat · Scope: add connections:write.

Daemonization

Run 24/7 in Background (Optional)

You can keep OpenCat running persistently in Linux/WSL so it's always ready, even after rebooting or closing your terminal.

# 1. Create a user systemd service (~/.config/systemd/user/opencat.service)
[Unit]
Description=OpenCat Slack Agent Listener
After=network.target

[Service]
ExecStart=/usr/bin/env npx @sheiksadi/opencat
Restart=always
RestartSec=5

# 2. Enable and start
systemctl --user enable --now opencat
loginctl enable-linger $USER
